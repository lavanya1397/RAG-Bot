#RAG PDF Chatbot
This is a chatbot built using Streamlit, LamgChain, FAISS, Hugging Face Embeddings and GROQ LLM API to answer all user queries based on document users upload.

#Features
Upload PDF documents
Extract and Chunk text
Generate embeddings using HuggingFace
Store Embeddings in FAISS
Retrieve relevant chunks using MMR retrieval
Generate grounded responses using Llama 3.1 via Groq
Display source citations
Conversational Chat Interface

#Tech Stack
Python
Streamlit
LangChain
FAISS
HuggingFace Embeddings
Groq API
Llama 3.1

#Usage
Upload a PDF document
Ask questions about the document 
Review retrieved sources alongside generated answers
